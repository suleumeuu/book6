# C++ электрондық оқу құралы — GitHub Pages

## Файлдар
- `index.html` — PDF оқу интерфейсі: мазмұн, бетке өту, масштаб, іздеу, толық экран.
- `textbook.pdf` — C++ оқу құралы.

## GitHub Pages-ке жариялау
1. GitHub-та жаңа **Public** репозиторий ашыңыз, мысалы `cpp-lab-site`.
2. `index.html`, `textbook.pdf` және `README.md` файлдарын репозиторийдің негізгі бетіне жүктеңіз.
3. Репозиторийде **Settings → Pages** бөліміне кіріңіз.
4. **Deploy from a branch** таңдаңыз, branch ретінде `main`, folder ретінде `/(root)` қойып, **Save** басыңыз.
5. Бірнеше минуттан кейін сайт `https://USERNAME.github.io/cpp-lab-site/` мекенжайында ашылады.

## Ескерту
- PDF.js кітапханасы CDN арқылы жүктеледі, сондықтан сайтты ашқанда интернет қажет.
- Мазмұндағы бет нөмірлері навигация үлгісі ретінде берілген; егер PDF-тегі нақты бөлім беттері өзгеше болса, `index.html` ішіндегі `data-page` мәндерін түзетіңіз.
- Әр зертханалық жұмысқа арналған YouTube батырмасы сол тақырып бойынша іздеу нәтижелерін ашады, нақты бір видеоны таңдаған емес.
